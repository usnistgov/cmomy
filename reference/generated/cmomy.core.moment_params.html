classmethod factory_mom(mom, mom_params=None, axes=None, default_ndim=None)[source]#

Factory method to validate mom and create mom_params object.

Parameters:

  • mom (int | Sequence[int]) – Order or moments. If integer or length one tuple, then moments are for a single variable. If length 2 tuple, then comoments of two variables

  • mom_params (MomParams | MomParamsBase | MomParamsDict | None, default: None) – Moment parameters. You can set moment parameters axes and dims using this option. For example, passing mom_params={"dim": ("a", "b")} is equivalent to passing mom_dims=("a", "b"). You can also pass as a MomParams object with mom_params=cmomy.MomParams(dims=("a", "b")).

  • axes (int | Sequence[int] | None, default: None) – Axes/Axis for moment dimension(s) (equivalent to mom_ndim).

  • default_ndim (MomNDim | None, default: None) – Fallback value for ndim.

axes_data_reduction(*inner, axis, out_has_axis=False)[source]#

Axes for reducing data along axis

if out_has_axis == True, then treat like resample, so output will still have axis with new size in output.

It is assumed that axis is validated against a moments array, (i.e., negative values should be < -mom_ndim)

Can also pass in “inner” dimensions (elements 1:-1 of output)

Factory method to create mom_params.

  • target (DataArray | Dataset), *, mom_params (MomParams | MomParamsBase | MomParamsDict | None) = ..., ndim (int | None) = ..., axes (int | Sequence[int] | None) = ..., dims (Hashable | Sequence[Hashable] | None) = ..., data (object) = ..., default_ndim (MomNDim | None) = ... → MomParamsXArray
